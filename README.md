The main purpose of this lab was to get familiar with the basic operations of Git and GitHub. By completing the tasks, I learned how a project can be stored online and how different versions of a file can be maintained.
For the lab task, I first created a public repository named **git-practice** on GitHub. I added the provided C++ program to a file named `main.cpp` and recorded the first version of the file with the commit message **"Initial commit."** This helped me understand how a project is initially saved in a Git repository.
I then brought the repository to my local computer using `git clone`. After entering the project directory, I used `git status` to inspect the repository. At that stage, Git reported that everything was up to date and there were no uncommitted changes.
The next task was to modify the C++ file. I opened `main.cpp` and entered the required personal information, including my name, student ID, and section. I also made the additional change specified in the lab instructions. The `git diff` command allowed me to examine the exact differences between the original and modified versions. I used `git status` again to verify that Git had recognized the changes.
After checking the modifications, I selected `main.cpp` for the next commit by using `git add main.cpp`. I then created a new version of the project with the commit message **"Updated student information."** Finally, I connected the local changes with the online repository by running `git push`. When I checked GitHub afterward, the modified file was visible in the repository.
This lab was useful because I was able to perform the complete process of working with a Git repository instead of only learning the commands theoretically. I now have a better understanding of how Git helps keep track of modifications and how GitHub can be used to store and update a project remotely. The practical use of cloning, checking, comparing, staging, committing, and pushing changes also gave me a clearer idea of how version control is used in real software development.
